# Security and privacy reporting

Please do not publish credentials, cookies, authorization headers, or full signed S3 URLs in GitHub issues.

For a report, describe the affected extension version, browser version, reproduction steps, and what information may be exposed. Use a private reporting channel controlled by the repository owner for sensitive issues.

This project is designed to process course resources locally. Changes that add remote transmission, telemetry, broader host permissions, or credential access should be treated as privacy-sensitive and documented clearly.
