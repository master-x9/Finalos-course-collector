# Changelog

## 0.4.0

- Removed the persistent in-page collector panel.
- Added a toolbar ON/OFF switch for automatic save prompts.
- Added support for the `.tutorial-content-container` and `text-learning-card` Markdown layouts.
- Added cleaner text formatting for headings, lists, alerts, tables, inline code, and Ace-rendered examples.
- Split recognized MCQs into a separately labeled section of the reading `.txt` export.
- Preserved editable filenames for `.srt` and `.txt` exports.

## 0.3.x

- Added a toolbar setting to enable or disable automatic prompts.
- Removed the persistent page panel.
- Corrected transcript Blob download naming to use the filename entered by the user.

## 0.2.x

- Changed reading export to plain `.txt` instead of a ZIP archive.
- Added automatic save prompts for supported video transcript and reading sessions.

## 0.1.x

- Initial transcript and reading-material collection prototype.
